# Финансовый помощник

Личное мобильное веб-приложение (PWA **и** Telegram Mini App) для финансового учёта. Все данные хранятся **только на устройстве** (IndexedDB), никакой сервер и внешние API для базовой работы не нужны.

**Живая версия: <https://tankecu.github.io/finassistant/>** — хостится бесплатно на GitHub Pages, ничего запускать не нужно.

## Открыть в Telegram (Mini App)

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и username. Получите токен.
2. В BotFather: `/mybots` → ваш бот → **Bot Settings → Menu Button → Configure menu button** → отправьте ссылку `https://tankecu.github.io/finassistant/` → придумайте текст кнопки (например «Открыть»).
3. Готово: у бота слева от поля ввода появится кнопка, открывающая приложение. Кнопку бота можно закрепить (`/setuserpic` для иконки).

Приложение внутри Telegram получает тёмную тему, разворот на весь экран, вибрацию при сохранении и системную кнопку «Назад» для закрытия шитов. Данные лежат в хранилище веб-вью Telegram — экспортируйте JSON в настройках как резервную копию.

## Быстрый ввод (главный сценарий)

Кнопка **+** внизу → пишете фразу обычным языком:

- `потратил 35к на еду` → Расход 35 000 UZS, категория «Еда»
- `получил 500 долларов за работу` → Доход 500 USD
- `отложил 100 долларов на Америку` → Накопление к цели «Америка»
- `купил наушники за 40 долларов` → Расход + карточка покупки «Наушники»
- `перевел с карты на наличные 100$` → Перевод (не доход/расход)
- `обменял 1 миллион на доллары` → Перевод на счёт в USD
- `вчера потратил 85 тысяч на такси` → дата «вчера», категория «Транспорт»

Понимает: `35к`, `2 млн`, `1.5m`, `$100`, `100$`, `100 долларов`, `12,5`, `1 500 000`, даты `сегодня/вчера/позавчера/3 октября/03.10/в пятницу`.

### Комиссия при обмене валют

При переводе между счетами в разных валютах показывается поле **«Получите»** (предзаполнено по курсу). Если фактическая сумма меньше — разница автоматически записывается расходом **«Комиссия обмена»** (💱) со счёта-источника: нетворс падает ровно на комиссию, как в жизни. Выгодный обмен, наоборот, увеличивает капитал. Удаляешь перевод — комиссия удаляется вместе с ним.

## Структура

```
src/
  db/            схема Dexie (IndexedDB) + сид категорий и курсов
  services/
    parser/      парсер быстрого ввода (+ 24 теста)
    selectors.ts расчёты: балансы, нетворс, статистика, прогресс целей
    insights.ts  автоматические наблюдения (факты, без советов)
    transactions.ts  сохранение, конвертация валют, комиссия обмена
    speech.ts    голосовой ввод (Web Speech → заменяемый провайдер)
    exportImport.ts  JSON/CSV экспорт, импорт, демо-данные
  features/      dashboard, quickadd, transactions, analytics, goals,
                 accounts, purchases, wishlist, budgets, recurring,
                 notes, categories, settings, onboarding
  components/    UI-кит, SVG-графики (без внешних зависимостей)
  lib/telegram.ts  интеграция с Telegram Mini App
  lib/money.ts   деньги в minor units, конвертация
```

## Модель данных

- **Account** — наличные / карта / банк / кошелёк / накопления / инвестиции / крипта / активы / обязательства. Ликвидные считаются из операций; активы и долги — ручными оценками с историей.
- **Transaction** — `income | expense | transfer | savings`. Перевод меняет структуру активов, но не капитал. Суммы в минорных единицах в валюте счёта; мультивалютные переводы — поле `toAmount`; комиссия — связанный расход (`relatedId`).
- **Goal** — цель с прогрессом и прогнозом; **Purchase** — карточка покупки (зачем/плюсы/минусы/оценка 1–10); **Budget** — месячные лимиты; **Recurring** — регулярные платежи; **Note** — заметки со связями; **ExchangeRate** — курсы к базовой валюте (UZS по умолчанию).

NET WORTH = Активы − Обязательства, всё приводится к базовой валюте.

## Данные — ваши

- «Настройки → Экспорт JSON» — полная резервная копия; «Импорт» восстанавливает.
- «Экспорт CSV» — транзакции для Excel/Google Sheets.
- «Загрузить демо-данные» — 4 месяца правдоподобных операций; «Удалить все данные» — полная очистка.

## Подключение backend (задел на будущее)

Весь доступ к данным — через сервисный слой (`src/services/*`) над Dexie: для синхронизации между устройствами достаточно заменить репозитории на REST-клиент, UI и расчёты не меняются. Курсы валют и распознавание речи — интерфейсы с одним провайдером, готовые к внешним API.
