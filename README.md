# Финансовый помощник

Личное мобильное веб-приложение (PWA) для финансового учёта. Все данные хранятся **только на устройстве** (IndexedDB), никаких внешних API для базовой работы не требуется.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Production-сборка и превью:

```bash
npm run build
npm run preview
```

Тесты:

```bash
npm test
```

## Установка на телефон (PWA)

1. Откройте приложение в Chrome (Android) или Safari (iOS) по адресу dev-сервера либо размещённой сборки.
2. Android: меню → «Установить приложение». iOS: Поделиться → «На экран „Домой“».
3. Приложение работает офлайн: просмотр, ввод операций, статистика — всё локально.

## Быстрый ввод (главный сценарий)

Кнопка **+** внизу → пишете фразу обычным языком:

- `потратил 35к на еду` → Расход 35 000 UZS, категория «Еда»
- `получил 500 долларов за работу` → Доход 500 USD
- `отложил 100 долларов на Америку` → Накопление к цели «Америка»
- `купил наушники за 40 долларов` → Расход + карточка покупки «Наушники»
- `перевел с карты на наличные 100$` → Перевод (не доход/расход)
- `вчера потратил 85 тысяч на такси` → дата «вчера», категория «Транспорт»

Парсер понимает: `35к`, `2 млн`, `1.5m`, `$100`, `100$`, `100 долларов`, `12,5`, `1 500 000`, даты `сегодня/вчера/3 октября/03.10`. Категории распознаются по ключевым словам (редактируются в «Ещё → Категории»).

Микрофон — голосовой ввод (Web Speech API, работает в Chrome/Safari; слой заменяем на внешний STT).

## Структура

```
src/
  db/            схема Dexie (IndexedDB) + сид категорий и курсов
  services/
    parser/      парсер быстрого ввода (+ 22 теста)
    selectors.ts все расчёты: балансы, нетворс, статистика, прогресс целей
    insights.ts  автоматические наблюдения (факты, без советов)
    transactions.ts  сохранение с конвертацией валюты счёта
    speech.ts    слой голосового ввода (Web Speech → заменимый провайдер)
    exportImport.ts  JSON/CSV экспорт, импорт, демо-данные
  features/      экраны: dashboard, quickadd, transactions, analytics,
                 goals, accounts, purchases, wishlist, budgets,
                 recurring, notes, categories, settings
  components/    UI-кит и SVG-графики (без внешних зависимостей)
  lib/           деньги (minor units), даты, утилиты
```

## Модель данных

- **Account** — наличные / карта / банк / кошелёк / накопления / инвестиции / крипта / активы / обязательства. Ликвидные счёта считаются из операций; активы и долги — ручными оценками с историей.
- **Transaction** — `income | expense | transfer | savings`. Перевод меняет структуру активов, но не капитал. Суммы хранятся в минорных единицах, в валюте счёта; мультивалютные переводы — поле `toAmount`.
- **Goal** — цель с прогрессом (баланс привязанного счёта или сумма накоплений).
- **Purchase** — карточка покупки: зачем, что получил, плюсы/минусы, «стоило ли», оценка 1–10.
- **Budget** — месячный лимит по категории (аналитика, не запрет).
- **Recurring** — регулярные платежи с ручным или авто-проведением.
- **Note** — заметки с привязкой к операции/покупке/категории/цели/дате.
- **ExchangeRate** — курсы к базовой валюте (по умолчанию UZS), редактируются в настройках.

NET WORTH = Активы − Обязательства, всё приводится к базовой валюте.

## Данные — ваши

- «Настройки → Экспорт JSON» — полная резервная копия (и восстановление через «Импорт»).
- «Экспорт CSV» — транзакции для Excel/Google Sheets.
- «Загрузить демо-данные» — 4 месяца правдоподобных операций для знакомства (удаляется кнопкой «Удалить все данные»).

## Подключение backend (задел на будущее)

Весь доступ к данным — через сервисный слой (`src/services/*`) над Dexie. Для синхронизации между устройствами достаточно заменить репозитории на REST-клиент: UI и расчёты не меняются. Курсы валют (`services/entities.ts: saveRate`) и распознавание речи (`services/speech.ts`) — интерфейсы с одним провайдером, готовые к подключению внешних API.
